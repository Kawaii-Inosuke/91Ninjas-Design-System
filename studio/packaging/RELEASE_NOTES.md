## Download
- **Windows:** `91ninjas-studio-…-windows-x64.msi`
- **Mac with Apple chips (M1, M2, M3…):** `91ninjas-studio-…-macos-arm64.dmg`
- **Mac with Intel chips:** `91ninjas-studio-…-macos-x86_64.dmg`

## First install (once per laptop)
- **Windows:** if it says "Windows protected your PC", click **More info → Run anyway**. The setup adds a Start menu
  entry and a desktop icon.
- **Mac:** open the .dmg and drag **91Ninjas Studio** into Applications. On the first open, if macOS says it can't
  verify the app: **System Settings → Privacy & Security → Open Anyway**.
- The first start takes a few minutes while the app gets its AI tools ready (needs internet).
- Then open the AI panel's **Claude** tab and press **Set up Claude Desktop** (or **Connect Claude Code**).

## Updates
The app tells you when a new version is out and asks before installing. Updates don't show the warning above.
Your clients, designs and settings are kept.
