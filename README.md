# 91Ninjas Design System: 91 Studio

An AI design app for 91Ninjas designers. **AI agents create on-brand designs** (infographics first) from a client's design language, rulebook and past work. The results land on an **Illustrator-style editor** as editable layers, where designers finish them with professional vector tools.

- App, code and docs: [`studio/`](studio/README.md)
- Start reading at [`studio/docs/PRD.md`](studio/docs/PRD.md), then [`ARCHITECTURE.md`](studio/docs/ARCHITECTURE.md) and [`DECISIONS.md`](studio/docs/DECISIONS.md)
- Current status: the latest file in [`studio/docs/phases/`](studio/docs/phases/)

The editor in `studio/editor/` is a vendored fork of [VectorCraft](https://github.com/storytold/vectorcraft) (MIT / Apache-2.0). See [`studio/docs/UPSTREAM.md`](studio/docs/UPSTREAM.md).
